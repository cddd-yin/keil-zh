# 开发与验证记录

> 环境：Windows（中文系统）· Keil µVision **5.40.0.0**（`%LOCALAPPDATA%\Keil_v5\UV4\UV4.exe`）·
> Python 3.12（纯标准库）· 重写并验证日期：2026-10-06

## 0. 一句话结论

µVision 的界面文字都在 `UV4.exe` 的 Win32 资源中；用官方资源 API 把 `1033`（英文）
资源中的字符串表、菜单、对话框文本按“**资源身份 + 原文 SHA-256 指纹**”替换为简体中文，
**就地写回 `UV4.exe`**（首次自动备份 `UV4.exe.bak`），实现“**双击桌面 Keil 图标即中文**”。
只改 `.rsrc`、代码与数据段逐字节不变，可一键还原。**结论：可行 ✅**

设计参照 GitHub 项目
[`player4086/keil-uv5-zh-cn-patch`](https://github.com/player4086/keil-uv5-zh-cn-patch)
的“原文指纹”方案；相对参考项目增加：**对话框**覆盖、**原地汉化**模式、写入前逐段校验。

## 1. 可行性调查

1. `UV4.exe`（12,645,672 字节，版本 5.40.0.0）资源统计：

   | 类型 | 数量 | 说明 |
   | --- | --- | --- |
   | RT_STRING (6) | 259 | 字符串表，共 955 条非空英文 |
   | RT_MENU (4) | 40 | 菜单，318 个有文字的菜单项 |
   | RT_DIALOG (5) | 246 | 对话框，2294 处文本 |
   | 其它 | — | 图标/位图/PNG/版本信息等 |

2. 语言资源：`1033`（主）、`2057`（少量）、`1041` 日语（**仅字符串表 534 条**）。
   → 说明官方“本地化”机制只覆盖字符串表；菜单/对话框无论语言都读英文资源。

3. 桌面快捷方式 `Keil uVision5.LNK` 指向 `%LOCALAPPDATA%\Keil_v5\UV4\UV4.exe`，
   因此“双击桌面图标即中文”要求**就地改写**该文件，而不是另生成副本。

## 2. 架构（参照参考项目并扩展）

| 文件 | 作用 |
| --- | --- |
| `build_patch.py` | 生成器入口：版本/SHA-256 识别、兼容性检查、**原地写入 + 备份 + 逐段校验**、输出报告；`--copy` 可改为非破坏式 |
| `tools/pe_resources.py` | PE 资源读写（字符串表编解码、CJK 判定、资源摘要） |
| `tools/resource_formats.py` | Win32 菜单/对话框解析与序列化 |
| `tools/make_catalog.py` | 由 `translations/src/*.json` + 官方 UV4.exe 生成指纹词典 |
| `tools/validate_formats.py` | 菜单/对话框往返解析校验 |
| `tools/verify_pe_sections.py` | 比较两个 PE 文件各段的 SHA-256 |
| `tools/export_translation_catalog.py` | 由“原版/汉化版”对照导出指纹词典（维护者工具） |
| `tools/extract.py` | 导出界面资源（维护词典用） |
| `tools/restore.py` | 从 `UV4.exe.bak` 还原英文 |

## 6. 已知限制（无法通过资源方式解决）

- 「关于 µVision」许可正文等硬编码在 `.data` 的 ANSI 字符串；
- 少数属性表框架按钮（*Close / Help*）；
- 由代码用 `.rdata` 字面量设置的文本，如窗格标题（*Project*、*Build Output*）、*Recent Files* 等；
- 资源被改动后 Arm 的**数字签名失效**（任何资源汉化都无法避免）。

详见 [`原理与兼容性.md`](原理与兼容性.md) 第 6 节。

## 7. 复现步骤

```powershell
# 1. 生成指纹词典（需要本机已安装官方 UV4.exe）
python tools\make_catalog.py

# 2. 预览匹配（不写文件）
python build_patch.py --dry-run

# 3. 原地汉化（自动备份 UV4.exe.bak + 写入前逐段校验）
python build_patch.py

# 4. 校验仅资源段被改动
python tools\verify_pe_sections.py "C:\Keil_v5\UV4\UV4.exe.bak" "C:\Keil_v5\UV4\UV4.exe"

# 5. 校验菜单/对话框可无损解析
python tools\validate_formats.py "C:\Keil_v5\UV4\UV4.exe"

# 6. 还原英文
python tools\restore.py
```
