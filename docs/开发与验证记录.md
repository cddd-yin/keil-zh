# 开发与验证记录

> 环境：Windows（中文系统）· Keil µVision **5.40.0.0**（`%LOCALAPPDATA%\Keil_v5\UV4\UV4.exe`）·
> Python 3.12（纯标准库）· 验证日期：2026-10-06

## 0. 一句话结论

µVision 的界面文字都在 `UV4.exe` 的 Win32 资源中；用官方资源 API 把 `1033`（英文）
资源中的字符串表、菜单、对话框文本替换为简体中文，就地生成独立副本
`UV4_zh-CN.exe`，**只改资源、代码与数据段逐字节不变**，可一键还原。**结论：可行 ✅**

## 1. 可行性调查

1. `UV4.exe`（12,645,672 字节，版本 5.40.0.0）资源统计：

   | 类型 | 数量 | 说明 |
   | --- | --- | --- |
   | RT_STRING (6) | 259 | 字符串表，共 955 条非空英文 |
   | RT_MENU (4) | 40 | 菜单，318 个有文字的菜单项 |
   | RT_DIALOG (5) | 246 | 对话框，2294 处文本 |
   | 其它 | — | 图标/位图/PNG/版本信息等 |

2. 语言资源：`1033`（主）、`2057`（少量）、`1041` 日语（**仅字符串表 534 条**）。
   → 说明官方“本地化”机制只覆盖字符串表；菜单/对话框无论语言都读英文资源。

3. 结论：汉化 = 替换 `1033` 的字符串表 + 菜单 + 对话框文本，无需改二进制。

## 6. 复现步骤

```powershell
# 1. 导出资源（分析用）
python tools\extract.py "C:\Keil_v5\UV4\UV4.exe"

# 2. 生成翻译工作清单
python tools\make_worklists.py

# 3. 合并词典并查看覆盖率
python tools\make_catalog.py

# 4. 预览匹配（不写文件）
python tools\build_patch.py --dry-run

# 5. 生成中文副本
python tools\build_patch.py

# 6. 校验仅资源段被改动
python tools\verify_sections.py "C:\Keil_v5\UV4\UV4.exe" "C:\Keil_v5\UV4\UV4_zh-CN.exe"
```
